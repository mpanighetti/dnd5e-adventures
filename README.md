# README

This is a collection of adventures I have written for Dungeons & Dragons 5th Edition.

## General notes

At minimum, Game Masters will need the _SRD_ to run these adventures. Creatures from these sources are **bolded**, while magic items and spells are _italicized_. Stat blocks are also included for new or reskinned creatures and magic items; if a referenced creature or magic item is not in the _SRD_, it will either include a link to the content or be marked with a footnote indicating its source.

Any adventure including potentially sensitive topics will be preceded with a relevant content warning. I encourage you to set clear boundaries and expectations at your gaming table, ensuring that we keep the hobby inclusive and inviting to all. I've found Monte Cook's **Consent in Gaming** to be an excellent safety tool for your games (see **Third-Party Content References** below), but feel free to use whatever such tools you prefer.

The adventures in this document rely on "theater of the mind" and do not include maps.
